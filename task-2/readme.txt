# 📂 Task 2: Digital Portfolio

## 📌 Overview
This folder contains the screenshots of the digital profiles I created and updated as part of Task 2 of the Digital Literacy Project. The main objective of this task was to build a professional online presence using widely used platforms.

---

## 🌐 Platforms Used

### 🔹 GitHub
GitHub is a platform used for hosting and managing coding projects. I created my profile and added a profile README that includes my name, academic details, and learning goals. This will help me showcase my projects and track my progress over time.

### 🔹 LinkedIn
LinkedIn is a professional networking platform. I updated my profile by adding my education details such as my degree, university, and expected graduation year. This platform will help me build connections and explore internship and job opportunities.

### 🔹 Kaggle
Kaggle is a platform for data science and machine learning. I created a basic profile to explore datasets, learn new skills, and participate in competitions in the future.

This folder includes the following screenshots:

- GitHub Profile

## 🎯 Learning Outcome
Through this task, I learned the importance of maintaining a professional digital identity. Creating these profiles helped me understand how online platforms can be used to showcase skills, build networks, and prepare for future career opportunities.
